맘스터치가 `귀멸의 칼날: 무한성편` 재개봉을 기념해 굿즈 포함 세트 2종을 내놨다. 기간은 **2026년 9월 1일~9월 28일**. 선택지는 분명하다. 치킨과 버거를 넉넉히 먹으면서 문이 열리는 조명 굿즈를 노릴지, 버거 2개 구성에 메탈 일륜도 키링을 받을지다.

## 먼저 볼 핵심 정보

| 항목 | 내용 |
| :--- | :--- |
| 판매 기간 | 2026년 9월 1일~9월 28일 |
| 세트 종류 | LED 아크릴 스탠드 세트, 메탈 일륜도 키링 세트 |
| 굿즈 지급 방식 | 세트별 랜덤 1종 |
| 주의할 점 | 한정 수량 굿즈라 매장 재고가 소진되면 기간 전에도 판매가 끝날 수 있음 |

이번 행사는 작품을 보고 난 뒤 굿즈까지 챙기려는 팬을 겨냥한 구성이다. 단품 굿즈를 따로 고르는 방식이 아니라 **세트 1개당 랜덤 굿즈 1개**가 나온다. 원하는 캐릭터가 정해져 있다면 한 번의 주문으로 끝난다는 보장은 없다.

## 1. LED 아크릴 스탠드 세트: 25,200원

후라이드 빅싸이순살, 싸이버거, 콜라에 **LED 아크릴 스탠드 1개**가 포함된 세트다. 공식 포스터 기준 가격은 **25,200원**이다.

LED 스탠드는 단순 평면 아크릴이 아니다. 문을 여닫을 수 있는 구조와 터치식 조명이 들어간 형태다. 책상 위에 두고 무한성 분위기를 내고 싶다면 이쪽이 더 어울린다.

| 구성 | 수량 |
| :--- | :--- |
| 후라이드 빅싸이순살 | 1개 |
| 싸이버거 | 1개 |
| 콜라 | 1개 |
| LED 아크릴 스탠드 | 랜덤 1개, 총 7종 |

공식 포스터에 나온 7종은 **탄지로, 젠이츠, 시노부, 기유, 도우마, 아카자, 카이가쿠**다. 식사량은 두 사람이 나눠 먹기에도 무난한 편이지만, 음료는 1개라는 점은 주문 전에 알아둘 만하다.

## 2. 메탈 일륜도 키링 세트: 20,700원

메탈 일륜도 키링 세트는 **20,700원**으로 LED 세트보다 4,500원 저렴하다. 구성은 싸이버거 세트, 더블불고기버거, 메탈 일륜도 키링 1개다.

싸이버거 세트에는 감자와 음료가 포함되므로 버거 2개와 사이드까지 먹는 구성으로 보면 된다. 조명 스탠드보다 작은 굿즈를 선호하거나, 식사 메뉴 쪽을 더 챙기고 싶다면 이 세트가 맞다.

| 구성 | 수량 |
| :--- | :--- |
| 싸이버거 세트 | 1개 |
| 더블불고기버거 | 1개 |
| 메탈 일륜도 키링 세트 | 랜덤 1개, 총 4종 |

키링은 검은색 메탈 일륜도와 거치대가 함께 들어가는 형태다. 공식 포스터상 랜덤 캐릭터는 **탄지로, 젠이츠, 시노부, 기유** 4종이다. LED 아크릴 스탠드보다 후보 수가 적다는 점은 원하는 캐릭터를 노리는 사람에게 작은 차이다.

## 두 세트, 이렇게 고르면 된다

| 이런 경우 | 추천 세트 | 이유 |
| :--- | :--- | :--- |
| 책상용 전시 굿즈가 우선 | LED 아크릴 스탠드 세트 | 터치 조명과 개폐 구조가 핵심 |
| 버거와 사이드를 든든하게 먹고 싶음 | 메탈 일륜도 키링 세트 | 싸이버거 세트와 더블불고기버거 구성 |
| 랜덤 후보 수를 줄이고 싶음 | 메탈 일륜도 키링 세트 | 4종 랜덤, LED 스탠드는 7종 랜덤 |
| 치킨까지 포함된 식사를 원함 | LED 아크릴 스탠드 세트 | 빅싸이순살과 싸이버거를 함께 제공 |

가격만 보면 키링 세트가 부담이 적다. 다만 이번 콜라보의 특징인 ‘문이 열리는 터치식 조명’을 원한다면 4,500원을 더 내고 LED 세트를 고르는 이유가 분명하다.

> 원하는 캐릭터가 있다면 주문 직전에 매장 또는 맘스터치 앱에서 해당 콜라보 세트의 판매 여부를 확인하는 편이 좋다. 세트는 9월 28일까지 운영 예정이지만, 굿즈는 한정 수량이라 조기 종료될 수 있다.
