스타벅스가 **2026년 9월 7일(월)부터 9월 20일(일)까지 14일간** `라떼 위크`를 진행합니다. 스타벅스 리워드 회원이라면 매일 한 번 룰렛에 참여할 수 있고, 결과로 대상 라떼 **50% 할인·30% 할인·1+1·사이즈업·별 1개** 중 하나를 받습니다.

핵심은 단순합니다. **룰렛은 꽝이 없지만 50% 할인은 랜덤 당첨 혜택**입니다. 한 번 돌린 뒤 쿠폰함을 바로 열고, 당일 안에 대상 음료 한 잔을 주문해야 할인 쿠폰을 놓치지 않습니다.

![스타벅스 라떼 위크 공식 대표 이미지](/assets/images/life/20260909_starbucks_latte_week_01_cover.png)

## 한눈에 보는 라떼 위크 일정과 대상

| 구분 | 내용 |
| :--- | :--- |
| 행사 기간 | 2026년 9월 7일(월)~9월 20일(일), 14일간 |
| 참여 대상 | 스타벅스 리워드 전 회원 |
| 참여 횟수 | 이벤트 기간 중 매일 1회 |
| 참여 경로 | 스타벅스 앱 사이렌 오더 내 라떼 위크 룰렛 |
| 쿠폰 사용 | 발행 당일까지만, 대상 음료 1잔 주문 시 적용 |
| 신규 가입자 | 가입 1일 후부터 참여 가능 |

라떼 위크 쿠폰은 다음 10종에 적용됩니다. 가을 시즌 메뉴인 **블랙 글레이즈드 라떼**와 **호지 글레이즈드 티 라떼**도 포함돼, 평소 신메뉴 가격이 망설여졌다면 먼저 노려볼 만합니다.

| 커피 베이스 | 티 베이스·시즌 메뉴 |
| :--- | :--- |
| 바닐라 라떼, 스타벅스 돌체 라떼, 카페 라떼, 밀크카라멜 라떼, 플랫 화이트, 코르타도 | 블랙 글레이즈드 라떼, 호지 글레이즈드 티 라떼, 얼 그레이 바닐라 티 라떼, 제주 말차 라떼 |

![라떼 위크 대상 음료와 참여 대상 안내](/assets/images/life/20260909_starbucks_latte_week_02_roulette.png)

## 룰렛부터 결제까지, 실제 순서

1. 스타벅스 앱에서 라떼 위크 이벤트를 열고 그날의 룰렛을 돌립니다.
2. 결과는 자동으로 쿠폰함 또는 별 적립 내역에 반영됩니다.
3. 할인·1+1·사이즈업 쿠폰이 나왔다면 사이렌 오더에서 대상 음료를 담습니다.
4. 주문 화면에서 발급된 쿠폰을 적용해 **그날 안에** 결제합니다.

쿠폰은 다음 날로 넘길 수 없습니다. 오전에 룰렛만 돌려두고 잊기 쉬운 구조라서, 출근길이나 점심 주문 직전에 참여하는 편이 가장 실용적입니다. 이벤트 참여 기회는 매일 새로 갱신되고 시스템 상황에 따라 오전 중 순차 반영될 수 있습니다.

![라떼 위크 룰렛 참여와 쿠폰 사용 3단계](/assets/images/life/20260909_starbucks_latte_week_03_steps.png)

## 오늘 받을 수 있는 5가지 혜택

룰렛을 돌리면 아래 다섯 가지 중 하나가 랜덤으로 지급됩니다. 즉, 참여 자체는 꽝이 없지만 할인율과 혜택 종류는 고를 수 없습니다.

| 룰렛 결과 | 쓸모 있게 쓰는 방법 |
| :--- | :--- |
| 대상 음료 50% 할인 | 평소 가격대가 높은 시즌 라떼를 주문할 때 |
| 대상 음료 30% 할인 | 기본 라떼를 가볍게 할인받고 싶을 때 |
| 대상 음료 1+1 | 동료·친구와 같은 대상 음료를 나눌 때 |
| 대상 음료 사이즈업 | 톨보다 큰 사이즈를 선택할 계획일 때 |
| 별 1개 | 음료 주문 계획이 없는 날에도 적립 혜택으로 받기 |

![라떼 위크 룰렛 당첨 혜택 5종](/assets/images/life/20260909_starbucks_latte_week_04_rewards.png)

## 놓치기 쉬운 유의사항

> **하루 한 잔만 주문할 계획이라면:** 룰렛을 먼저 돌리고 쿠폰함을 확인한 뒤 메뉴를 고르세요. 50% 할인이나 1+1이 나왔을 때 주문 전략이 달라집니다.

- 쿠폰은 **대상 음료 1잔 주문 시에만** 적용됩니다.
- 할인 쿠폰은 발급일 당일까지 사용할 수 있고, 선물하기는 불가능합니다.
- 임직원 할인, 버디패스 등 다른 쿠폰 혜택과 중복 적용되지 않습니다.
- 현금이나 다른 상품으로 바꿀 수 없습니다.
- 매장별 재고와 판매 여부가 다를 수 있습니다.
- 별 1개는 지급일로부터 60일간 유효합니다.
- 쿠폰의 적용 대상은 스타벅스 정책에 따라 바뀔 수 있으므로, 주문 전 쿠폰 유의사항을 한 번 확인하세요.

![스타벅스 라떼 위크 쿠폰 유의사항](/assets/images/life/20260909_starbucks_latte_week_05_terms.png)

## 결론: 매일 한 번, 주문하는 날에 바로 쓰기

라떼 위크는 14일 동안 매일 참여할 수 있어 한 번의 당첨 결과에 아쉬워할 필요는 없습니다. 대신 **앱 룰렛 → 쿠폰함 확인 → 당일 사이렌 오더** 순서를 지키는 것이 전부입니다. 블랙 글레이즈드 라떼나 호지 글레이즈드 티 라떼를 마셔볼 계획이 있다면, 먼저 룰렛을 돌린 뒤 쿠폰 결과에 맞춰 주문하세요.
